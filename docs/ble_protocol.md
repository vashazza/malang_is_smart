# 스마트 말랑이 BLE 통신 규약 (v0.1 draft)

펌웨어팀과 앱팀이 공유하는 인터페이스 문서. **이 문서가 양쪽의 단일 진실(Single Source of Truth).**
바뀌면 양쪽 모두 갱신.

---

## 1. 디바이스 정보

- **기기명 (Advertised Name):** `MALLANGI` (앞 8자 이내)
- **MTU 권장:** 185 (BLE 기본 23보다 크게)
- **연결 모드:** Central(앱) ↔ Peripheral(ESP32)

## 2. GATT 구조

### Service: `MALLANGI_SERVICE`
- **UUID:** `6f9c0001-b5a3-4e1f-9d2a-5c7e8f0d1b2a`
- (커스텀 128bit UUID. 앱 코드에서 `BLE_SERVICE_UUID` 상수로 관리)

### Characteristics

| 이름 | UUID 끝자리 | 권한 | 길이 | 설명 |
|---|---|---|---|---|
| `SENSOR_STREAM` | `...0002...` | Notify | 16 B | 압력 5채널 + IMU 3축 실시간 스트림 (50Hz) |
| `CONTROL` | `...0003...` | Write | 1~4 B | 앱 → 기기 명령 (세션 시작/종료, 경도 단계) |
| `STATUS` | `...0004...` | Read+Notify | 4 B | 배터리 %, 현재 경도 단계, 펌프 상태 |
| `DEVICE_INFO` | `...0005...` | Read | 가변 | 펌웨어 버전, 디바이스 ID |

전체 UUID는 `src/ble/uuids.ts` 참고.

## 3. SENSOR_STREAM 패킷 포맷 (16 byte)

리틀엔디안. `Notify`로 50Hz (20ms 간격) 송신.

| 오프셋 | 크기 | 타입 | 필드 | 의미 |
|---|---|---|---|---|
| 0 | 2 | uint16 | `seq` | 패킷 시퀀스 번호 (0~65535 순환) |
| 2 | 2 | uint16 | `p1` | 손가락1(엄지) Velostat ADC raw (0~4095) |
| 4 | 2 | uint16 | `p2` | 손가락2(검지) |
| 6 | 2 | uint16 | `p3` | 손가락3(중지) |
| 8 | 2 | uint16 | `p4` | 손가락4(약지) |
| 10 | 2 | uint16 | `p5` | 손가락5(소지) |
| 12 | 1 | int8   | `ax` | MPU-6050 X (±2g 풀스케일을 -127~127로 양자화) |
| 13 | 1 | int8   | `ay` | Y |
| 14 | 1 | int8   | `az` | Z |
| 15 | 1 | uint8  | `flags` | bit0=세션중, bit1=쥐고있음(임계치 초과), bit2~3=경도단계 |

> **결정사항:**
> - 압력은 ADC raw로 보냄. 캘리브레이션은 앱에서 수행.
> - 50Hz는 손가락 빠른 쥐기 검출에 충분. 더 필요하면 100Hz로 상향.
> - 절대 시각은 앱이 패킷 수신 시각으로 부여 (`performance.now()`). 기기는 `seq`만 책임.

## 4. CONTROL 명령 (앱 → 기기, Write)

첫 바이트가 명령 코드.

| 코드 | 이름 | 추가 데이터 | 동작 |
|---|---|---|---|
| `0x01` | `START_SESSION` | 1 B 모드(0=쥐기, 1=리듬, 2=핀치) | 세션 시작, 스트림 ON |
| `0x02` | `STOP_SESSION` | 없음 | 세션 종료, 스트림 OFF |
| `0x03` | `SET_HARDNESS` | 1 B 단계(0=쉬움, 1=보통, 2=어려움) | 펌프로 에어백 압력 조정 |
| `0x04` | `CALIBRATE_ZERO` | 없음 | 현재 압력값을 0으로 영점화 |
| `0x05` | `PING` | 없음 | 응답 STATUS notify로 옴 |

## 5. STATUS 패킷 (4 byte, Read+Notify)

| 오프셋 | 크기 | 필드 | 의미 |
|---|---|---|---|
| 0 | 1 | `battery` | 0~100 (%) |
| 1 | 1 | `hardness` | 현재 경도 단계 (0~2) |
| 2 | 1 | `state` | 0=대기, 1=세션중, 2=캘리브레이션, 3=오류 |
| 3 | 1 | `errorCode` | 0=정상 외 코드는 펌웨어 README 참조 |

## 6. 데이터 흐름 시나리오

```
[앱]                                          [ESP32]
  │  scan & connect                              │
  │ ──────────────────────────────────────────▶ │
  │  read DEVICE_INFO                            │
  │ ──────────────────────────────────────────▶ │
  │  subscribe SENSOR_STREAM (notify)            │
  │ ──────────────────────────────────────────▶ │
  │  write CONTROL: START_SESSION(mode=쥐기)     │
  │ ──────────────────────────────────────────▶ │
  │                                              │
  │ ◀────────── notify SENSOR_STREAM @50Hz ────  │
  │ ◀────────── notify SENSOR_STREAM @50Hz ────  │
  │  ... (사용자가 30초 운동) ...                │
  │                                              │
  │  write CONTROL: STOP_SESSION                 │
  │ ──────────────────────────────────────────▶ │
  │  앱: 신호처리 → 점수 계산 → DB 저장          │
```
